# BASE versus DIVERSE and Champion-2

The matched causal experiment found DIVERSE versus BASE at 220–180 (score
0.55; one-sided bootstrap 95% LCB 0.52). DIVERSE then beat historical
Champion-1 261–139 (score 0.6525; LCB 0.62), supporting Champion-2 promotion.

This is evidence that frozen forced-prefix diversity improved gameplay in this
matched experiment. It is not a claim that Champion-2 beats KataHex or MoHex.
